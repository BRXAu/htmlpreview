Notes

Open items and the limits of this test.

  • Decision
    NECF or NCEF in the file name?This zip is named NECF. The earlier version of this banner and the other 23 AGA0363 sizes on the preview site use NCEF. NECF (National Energy Customer Framework) looks like the correct spelling, but the names should match across the set before trafficking.
  • Info
    Revision of the earlier NCEF 160x600Compared with the NCEF 160x600 already on the preview site: the terms copy has new line breaks, the frame 1, 2 and 3 footers are nudged up, "Click for T&Cs" now shows on frame 3 only, the frame 2 colour-wheel transition timing changed and frame 3 no longer slides in.
  • Info
    Zip includes Mac system filesThe zip is 147.7KB (under the 150KB default) but contains 13 __MACOSX files. The validator accepted it, but some ad servers count or reject these. Re-zip without them (for example with zip -X, or the Finder's Compress after removing hidden files) before sending.
  • Info
    Tested with an adapted testThis banner uses BRX's older template engine (manifest.js, vendors.js, main.js), so it was tested with a version of the standard browser test adapted to that engine's frames, terms panel and CTA. The checks are the same, plus a 1px border check and a check that every exit opens clickTag.
  • Info
    Expected browser behaviour, not faultsChrome and Safari cancel the first load of the animated frame 1 image because the template reloads it with a cache-busting URL; the file loads and displays. Each run also logs 34 GSAP "target not found" console warnings from template elements this banner doesn't use. Neither is an error.
  • Action
    Test on real phones before launchThese runs use browser engines with device profiles. Check on one iPhone and one Android phone.
