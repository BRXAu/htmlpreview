Open items and the limits of this test.

  • Info
    Skill test build: stand-in layers and fontThis is a test of the BRX banner skill and is final with stand-ins: the five 3D layers are drawn in code and the copy is set in Helvetica Neue in place of Söhne. A real job would swap these in and re-test.
  • Info
    DV360 limits assumedNo publisher spec sheet for this test, so the skill's DV360 defaults apply: clickTag exit (standard casing), 150KB per zip, 15s animation. The DCM validator is used as the closest public check for DV360. The banners have no 1px border; the light image panel may need one if a publisher's spec asks.
  • Info
    3D intro checked in real SafariThe test WebKit build draws CSS 3D without perspective, so its screenshots show the cards face-on. Marty checked real Safari on a Mac on 19 October 2026 and the cards fan out in 3D as in Chrome and Firefox. Still to check on an iPhone.

    Test on real phones before launchThese runs use browser engines with device profiles. Check on one iPhone and one Android phone.
